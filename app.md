## Core feature set (extracted)

1. **Closet / wardrobe organizer** — add items via camera or gallery photo, tag category/color/season/occasion, organize into cabinets > categories > subcategories (Tops, Bottoms, Dresses, Shoes, Outerwear, Accessories).
2. **Outfit builder ("Mix")** — pick top/bottom/shoes/accessories piece by piece, layer belts/text/backgrounds, save as a named outfit (e.g. "Formal").
3. **Outfit discovery (swipe)** — swipe through auto-generated combinations, like/skip, save favorites — a "Tinder for outfits."
4. **Outfit planner calendar** — schedule an outfit to a specific date/time, attach event notes, see "Planner Insights" (planned days, total plans, next upcoming).
5. **Trip packing list generator** — build a trip, assign outfits per day, auto-generates a packing list from the pieces used.
6. **Search** — instant search across the whole wardrobe.
7. **Share/export** — export outfit collages to share on social / with friends.
8. **Privacy-first / offline-first** — wardrobe data and photos stored on-device, no mandatory cloud, encrypted, user can export/delete anytime, nothing sold or shared.
9. **Premium tier** — ₹399/mo or ₹2,999/yr (unlocks presumably unlimited items/outfits/AI styling — exact paywall gating not stated in listing).
